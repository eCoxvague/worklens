Small scope.
Verifiable progress.

This first release demonstrates score checking with a small QUBO problem. Next: read-only QMS block lookup, real problem data, and reproducible verification reports.

WorkLens is an independent community project. Current testnet problems are network-generated. The project checks score consistency; it does not certify global optimality or validate consensus.
